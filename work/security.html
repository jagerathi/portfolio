Cyber Security & Compliance

Endpoint compliance automation — STIG and CIS hardening and remediation for Linux systems.

As lead engineer on a Linux compliance agent, I built the client-side component responsible for bringing endpoints into line with security baselines and keeping them there. The agent was developed on .NET Core 8 and communicates with its host server over gRPC, which gave us an efficient, strongly-typed channel for streaming scan results and remediation status back to the control plane.

The core of the work was policy compliance: scanning systems against STIG (Security Technical Implementation Guides) and CIS benchmarks, reporting where they fell short, and remediating the drift. Working alongside Linux subject-matter experts, we translated those policies into bash scripts that could both assess a system's posture and safely correct it across Red Hat Enterprise Linux 8, RHEL 9, and Ubuntu 22.

Supporting multiple distributions is where the real care goes. A check that's correct on RHEL 9 may behave differently on Ubuntu 22, and remediation has to be safe to run repeatedly without breaking a working system. That meant treating idempotency and predictability as first-class requirements, and validating every control against each target platform rather than assuming parity.

Security also had to extend to the agent itself. I built the installer with Install Builder, paired with custom bash scripts that set up the application, provision and install its SSL certificates, and configure secure communication with the host server. The goal throughout was dependable, repeatable deployment into the kind of locked-down environments where compliance actually matters.
