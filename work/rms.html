Retail Management (RMS)

Retail management system with direct integration into several popular accounting systems.

After working on many sales-based extensions, we developed a commercial version that could serve as the base for new solutions. Retail Management was a fascinating project, especially coordinating inventory control between multiple stores. The challenges included real-time reporting, KPI tracking, and managing data integrations between stores and terminals.

High availability was a core feature, and it brought many challenges. Terminals needed to function stand-alone and then integrate their data back into the store server — and the store server had to do the same with the corporate data server.

Our system was hardware agnostic, which led to more challenges. It was built on a Microsoft tech stack (C++, MFC, and SQL), so supporting many different hardware platforms and accessories was essential. A hardware abstraction layer managed these complexities while keeping the system flexible and robust.

The crowning achievement was direct accounting-system integration. Through the Accounting System Interface (ASI) we downloaded inventory information each morning and uploaded sales data at the end of the day. The ASI acted as a bridge between the two systems. In the end we supported nearly a dozen systems from several major vendors.
