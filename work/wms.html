Warehouse Management (WMS)

Shipping, receiving, and inventory control with direct integration into several popular accounting systems.

Inventory management was a natural progression from Retail Management. Unlike the retail system, it required a real-time link with the companion accounting system — we could no longer rely on a batched interface. A new interface let us swap out components for integration into external processes.

This system was a fun and challenging venture, incorporating handheld and wearable computers to optimize the process for users. Unlike the high-volume, highly redundant retail setup, warehouse management required a finer degree of data control: it was imperative to prevent multiple users from processing the same information.

It was also a goal to normalize the process across multiple backend accounting packages. That meant fundamental concepts — bin tracking, lots, serial numbers — had to be managed externally. While this was a huge advantage to the customer, it made the implementation more complex.

Customization was a major consideration. To allow certain processes or UI entities to be customized, a COM-style interface let a new DLL be dropped into the runtime folder; it would match interface signatures and execute custom code on the core system.
